# Angelplayer 发布仓库

这里是 Angelplayer 的公开下载站。

## 特色

- **自研播放核心**：为电视大屏写的播放核心，4K 原画、高码率片源播放更稳。
- **双引擎可选**：自研核心与 ExoPlayer，设置里选默认引擎。
- **字幕**：内嵌 PGS / ASS / SRT 与外挂字幕，字号、位置、描边可调。
- **大屏界面**：遥控器操作，按钮与弹出框风格统一，详情、设置、播放里的选择更顺手。
- **继续观看**：打开就能接着看，首页 Hero 与继续观看一目了然。
- **手机扫码管理服务器**：电视上扫码，手机浏览器里配服务器，不用在电视上一个个字母敲。
- **直连 Emby**：连自己的 Emby 服务器就能看。

## 安装要求

- 系统：Android 8.0 及以上。
- 芯片：ARM 64 位或 ARM 32 位（v7a）设备；x86 设备装不上。
- 设备：为电视大屏、遥控器操作设计。
- 安装包约 61 MB，安装前请留出空间。
- 安装方式：不在应用商店上架，从 Releases 下载后侧载；电视上给用来安装的浏览器或文件管理器开“安装未知应用”权限。
- 旧版冲突：之前装过不同签名的同名应用，先卸载旧版再装。
- 设置页检查更新时，系统会要求允许安装未知应用，按提示允许即可。
- 装完使用：需要自己的 Emby 服务器和账号，电视要能连到该服务器。
