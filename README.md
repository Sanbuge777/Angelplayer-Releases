# Angelplayer 发布仓库

这里是 Angelplayer 的公开下载站。

## 特色

- **自研播放核心**：从零写的 C++ 播放核心，电视上 4K 高码率硬解、8K 播放稳定。
- **双引擎切换**：自研核心与 ExoPlayer，详情页按片源选。
- **字幕**：内嵌 PGS / ASS / SRT 与外挂字幕，字号、位置、描边可调。
- **电视大屏界面**：遥控器操作，详情页双行音轨 / 字幕选择，播放时 OSD 显示片源信息。
- **手机扫码管理服务器**：电视上扫码，手机浏览器里配服务器，不用在电视上一个个字母敲。
- **直连 Emby**：连自己的 Emby 服务器就能看。

## 当前状态

1.3.0 公开测试版已发布，去右侧 Releases 下载。测试版可能有已知问题，装之前先看当版 Release 说明里的“已知问题”。

## 开源组件说明

安装包内含 FFmpeg（LGPLv3）、libass 等开源组件。各组件源码获取方式与本次构建所用版本，见每次 Release 的说明。
