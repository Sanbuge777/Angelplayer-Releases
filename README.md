# Angelplayer 发布仓库

这里是 Angelplayer 的公开下载站：**只发安装包，不含源码**。

## 下载

打开右侧 **Releases**，下载最新版的 `.apk`。

## 安装

- 电视已开 ADB 调试：`adb install -r AngelPlayer-x.y.z.apk`
- 或把 APK 拷到 U 盘，在电视上用文件管理器安装。
- 各版本固定同一签名，可直接覆盖安装升级，无需卸载。

## 当前状态

首个公开测试版正在准备中，敬请期待。测试版可能有已知问题，装之前先看当版 Release 说明里的“已知问题”。

## 开源组件说明

安装包内含 FFmpeg（LGPLv3）、libass 等开源组件。各组件源码获取方式与本次构建所用版本，见每次 Release 的说明。
