# Angelplayer 发布仓库

这里是 Angelplayer 的公开下载站。

## 特色

- **自研播放核心**：为电视大屏写的播放核心，4K 原画、高码率片源播放更稳。
- **双引擎可选**：自研核心与 ExoPlayer，设置里选默认引擎。
- **字幕**：内嵌 PGS / ASS / SRT 与外挂字幕，字号、位置、描边可调。
- **大屏界面**：遥控器操作，按钮与弹出框风格统一，详情、设置、播放里的选择更顺手。
- **继续观看**：打开就能接着看，首页 Hero 与继续观看一目了然。
- **手机扫码管理服务器**：电视上扫码，手机浏览器里配服务器，不用在电视上一个个字母敲。
- **直连 Emby**：连自己的 Emby 服务器就能看。

## 当前版本

1.8.0 已发布，去右侧 Releases 下载。

## 开源组件说明

安装包内含 FFmpeg（LGPLv3）、libass 等开源组件。
